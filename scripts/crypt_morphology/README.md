# Crypt morphology batch scripts

Reserved for batch representation export after the staged validation is complete.
No mass exporter is implemented in step 1. The inspection notebooks live in
`notebooks/crypt_morphology/`; their reusable methods live in
`organograph.crypt_morphology` and `organograph.plotting.crypt_morphology`.

Future exports will contain fixed-basis geometry/field coefficients and their
provenance. Learned latent encoders and decoders belong to the separate learning
project.
